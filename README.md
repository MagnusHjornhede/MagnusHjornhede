### 🕹️ [**Kinect-Gesture-ML-Experiments**](https://github.com/MagnusHjornhede/kinect-gesture-ml-experiments)
**Skeleton-based gesture classification with structured ML experiments.**  
- Dataset: **242 skeleton-derived features** + labels.  
- 3 stages: preprocessing → baseline models → PCA(95%) benchmarking.  
- Key results:  
  - Without PCA → **ExtraTrees/RandomForest** best.  
  - With PCA → **Linear SVM** strongest baseline.  
🧠 _Python · scikit-learn · PCA/visualization notebooks_
